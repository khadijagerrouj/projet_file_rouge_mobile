## Prototype fonctionnel cible

Le prototype vise à valider les parcours essentiels avant d'ajouter des fonctions avancées.

| Priorité | Fonction | Résultat attendu |
|---|---|---|
| Essentielle | Administrer les podcasts | Créer et modifier le titre, la description et la catégorie |
| Essentielle | Administrer les épisodes | Associer un épisode à un podcast et gérer ses métadonnées |
| Essentielle | Contrôler la publication | Distinguer brouillon, publié et archivé |
| Essentielle | Parcourir le catalogue | Afficher les podcasts et épisodes publiés |
| Essentielle | Écouter un épisode | Ouvrir la ressource audio d'un épisode publié |
| Suivante | Rechercher et filtrer | Retrouver les podcasts par titre ou catégorie |

Ces fonctionnalités décrivent le prototype attendu. Leur état d'implémentation doit être renseigné à partir du code et des tests de l'application.

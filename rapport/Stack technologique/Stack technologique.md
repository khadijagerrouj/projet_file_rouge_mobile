## Stack technologique de référence

Les notes techniques du dossier mentionnent la pile suivante pour une application mobile :

- **PHP 8.2 et Laravel 12** pour les traitements métier et les opérations de gestion.
- **NativePHP** comme piste de distribution mobile de l'application Laravel.
- **Blade**, **Tailwind CSS** et **Alpine.js** pour construire l'interface.
- **Vite** pour préparer les ressources frontend.
- **MySQL** pour stocker les comptes, podcasts, épisodes et catégories.
- **Mermaid** pour documenter les flux et les modèles.

Pour les fichiers audio, la base de données conserve les métadonnées et une référence vers la ressource ; les fichiers volumineux nécessitent un stockage adapté.

Cette liste décrit la stack de référence figurant dans le dossier, et non une vérification du dépôt applicatif. Les versions, dépendances et technologies réellement utilisées sont à confirmer dans les fichiers de configuration du projet.
